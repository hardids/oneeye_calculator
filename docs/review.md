## 설계 선택

- 주요 결과를 가장 먼저 볼 수 있도록 짙은 녹색 결과 카드에 배치했습니다. 왼쪽은 조건, 오른쪽은 결과와 비교이며 모바일에서는 세로로 재배치합니다.
- 수동 ‘계산’ 버튼 대신 입력 시 바로 재계산하되, 오류 시 이전 금액을 결과처럼 남겨두지 않습니다.
- 상환 표와 그래프는 동일한 계산 결과를 사용합니다. 긴 기간의 그래프는 최대 12개 시점만 보여주고 전체 내역은 표와 CSV에서 제공합니다.
- 연봉 계산은 공식 간이세액표를 직접 조회합니다. 개인별 공제를 임의로 추정한 연간 세율 공식으로 대체하지 않습니다.
- 전용 84㎡는 전용 25.41평으로 환산합니다. 공급 평형은 자동 추정하지 않고 별도 입력값만 사용합니다.
- ‘연 실수령액’ 대신 ‘실수령액 연 환산’을 표시해 현재 월 계산값과 2026년 실제 연간 지급 합계를 구분합니다.
- 무료 브라우저 기능만으로 동작하도록 만들었습니다. 회원 시스템이나 민감정보 수집을 추가하지 않았습니다.

원본의 자유게시판·커뮤니티와 공개 계산 이력은 핵심 계산 기능과 분리했습니다. 금융상품 조회·실시간 금리·대출 승인/한도 판정·DTI/DSR 규제 판단은 구현하지 않았습니다. 현재 도구는 입력한 조건의 현금흐름을 계산하며 금융기관의 심사 결과를 예측하지 않습니다.
