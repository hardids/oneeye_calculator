# 한눈에 금융

대출·예금/적금·급여·면적을 계산하는 한국어 생활금융 웹 앱입니다. `best79.com`의 주요 기능을 분석해 화면과 계산 코드를 새로 구현했습니다.

**버전 1.1.0 · 검토일 2026-10-10 · 자동 테스트 23개 통과**

## GitHub Pages로 배포하기

1. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
2. 이 폴더 안의 파일을 저장소 `main` 브랜치 최상위에 업로드합니다. `.github` 폴더도 포함합니다.
3. **Actions → Test and deploy GitHub Pages**에서 성공 여부를 확인합니다. 테스트 통과 후 `dist/`의 웹 파일만 배포됩니다.

상세 안내: **[DEPLOY_GITHUB_PAGES.md](DEPLOY_GITHUB_PAGES.md)**. ZIP 자체가 아니라 압축을 푼 파일을 업로드해야 합니다.

`https://사용자명.github.io/저장소명/`과 사용자 홈페이지 주소를 모두 지원합니다. 저장소 이름을 코드에 입력할 필요가 없습니다. 백엔드, API 키, npm 의존 패키지, 빌드 과정이 필요 없는 정적 ES 모듈 앱입니다.

## 기능

- 대출: 원리금균등·원금균등·만기일시, 거치기간, 상환표, 방식 비교, 금리 시나리오.
- 저축: 예금·적금·세후 목표액 역산, 단리·월복리, 과세 선택, 납입 일정.
- 급여: 연봉/월급, 비과세액, 가족·자녀, 원천징수 비율, 공제 내역, 연봉별 비교.
- 면적: ㎡/평 변환, 전용·공급 평단가, 전용률, 자주 쓰는 면적 표.
- 공통: 즉시 재계산, 한글 금액 표시, 초기화, 최대 30건 브라우저 저장·불러오기·삭제, 조건 링크, CSV.

## 파일 구조

| 경로 | 내용 |
|---|---|
| `dist/index.html` | 웹페이지 진입점 |
| `dist/style.css`, `dist/favicon.svg` | 반응형 화면과 아이콘 |
| `dist/app.js` | 입력·화면·저장·공유·CSV |
| `dist/calc.js` | 대출·저축·면적 계산 |
| `dist/salary.js` | 급여·보험료·간이세액표 조회 |
| `dist/tax-table.js` | 2026년 3월 시행 세액표 646개 구간 |
| `dist/content.js` | 도움말, 계산 가정, 공식 출처 |
| `.github/workflows/pages.yml` | 테스트 후 Pages 자동 배포 |
| `tests/` | 계산·이벤트·배포 경로 검증 |
| `docs/` | 원본 분석, 재점검 결과, 세액표 출처 기록 |

`dist/` 안의 파일이 실제 서비스에 필요한 전체 웹 소스입니다. JavaScript는 압축·번들링하지 않았으므로 그대로 수정할 수 있습니다.

## 로컬 테스트와 실행

테스트에는 Node.js 24 이상이 필요합니다. 설치할 npm 패키지는 없습니다.

```sh
npm test
```

Python이 설치돼 있다면 다음 명령으로 로컬 화면을 열 수 있습니다.

```sh
python -m http.server 8000 --directory dist
```

`http://localhost:8000/`에 접속합니다. Windows에서 `python` 명령이 없으면 `py -m http.server 8000 --directory dist`를 사용하세요. 정적 서버 확장 프로그램도 사용할 수 있습니다. `index.html`을 더블클릭해 `file://`로 여는 방식은 ES 모듈 보안 정책 때문에 지원하지 않습니다.

## 계산 기준과 데이터

급여는 2026년 3월 시행 간이세액표, 2026년 건강·장기요양 요율, 2026년 7월 이후 국민연금 상·하한을 사용합니다. 일반 직장가입자의 월 예상치이며, 실제 신고 보수, 가입 제외·감면, 별도 상여·퇴직금, 보험료 정산, 연말정산 결과는 반영하지 않습니다. 연 환산액은 현재 월 예상액의 12배입니다.

대출·저축은 월 단위 계산입니다. 은행의 일할 계산과 원 단위 처리, 중도상환·해지 비용 등으로 실제 금액과 차이가 날 수 있습니다. 앱의 **계산식과 출처**에 가정과 공식 원문을 제공합니다.

입력은 브라우저에서 계산하고, 저장 버튼을 누른 조건만 `localStorage`에 보관합니다. 다른 기기와 동기화하지 않습니다. 동일한 GitHub 도메인의 다른 프로젝트와 저장 공간이 섞이지 않도록 사이트 경로를 구분합니다. 결과 링크에는 입력 금액과 조건이 들어 있습니다. 개인 저장 데이터는 소스에 포함되지 않습니다.

Google Fonts의 Noto Sans KR을 선택적으로 불러오며, 실패하면 시스템 한글 글꼴을 사용합니다. 외부 JavaScript 라이브러리나 특정 호스팅 서비스의 인증 코드에 의존하지 않습니다.

## 검증 범위와 유지관리

재점검 결과: **[docs/recheck-2026-10-10.md](docs/recheck-2026-10-10.md)**. 23개 테스트에는 계산 경계값, 단위 왕복, 저장·공유·CSV, GitHub Pages 하위 경로가 포함됩니다.

화면 이벤트는 DOM 어댑터에서 테스트했습니다. 실제 브라우저 레이아웃·모바일 실기기·네이티브 클립보드·스크린리더 검수는 수행하지 않았습니다. 사용자의 GitHub 계정에서 Actions를 실행한 상태도 아닙니다. 첫 배포 결과와 실제 화면을 확인해 주세요.

법령·요율 변경 시 `salary.js`, `tax-table.js`, `content.js`, 화면 기준일을 함께 갱신해야 합니다. 제도 변경을 자동 반영하는 기능은 없습니다.
